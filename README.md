# THAOS V8 — Integrated class depth

Текущая база сайта THAOS. Эта версия продолжает V7 и не меняет утверждённый визуальный язык.

## Главное изменение
- Глобальной вкладки «Навыки» больше нет.
- Пользователь открывает класс и сначала читает краткую сводку.
- В сводке сразу видны названия 5 базовых навыков.
- Кнопка «Навыки» раскрывает расширенную интерактивную ветку этого класса.
- В ветке: 5 базовых узлов, переключатель 4 Путей + `?`, 4 узла выбранного Пути и граница Перелома на 7 уровне.
- Каждый узел кликабельный и открывает описание справа.
- Соединительные линии между узлами пока намеренно не добавлены.

## Контент
В интерфейс внесены все уже утверждённые названия 12 классов, базовых навыков и Путей. Там, где полное механическое правило ещё не утверждено, оставлен структурированный слот без выдумывания новых правил.

Для Друида, Призывателя и Механиста используются известные зафиксированные описания базовых навыков; для Путей Друида внесены утверждённые названия навыков.

## Арты и иконки классов
- Арт: `assets/classes/art/{class-id}.webp` (также поддерживаются jpg/png)
- Иконка: `assets/classes/icons/{class-id}.svg`

## Мир
Сохраняется структура карты, государств, Пакта, легенд, мифов и праздников из предыдущей сборки.

## v10 dossier navigation
- `class.html?id=...`: floating previous/next class controls with cyclic navigation.
- `race.html?id=...`: the same previous/next controls for playable races.
- Left/Right keyboard arrows switch dossiers on desktop.
- Dossier navigation is immediate: no ash veil, fade, slide, or forced delay.
- On mobile the controls move to the bottom edge and show neighboring names permanently.


### Иконки классов и неоновая карта (V13)

- На экране «Выберите класс» используются исходные `assets/classes/icons/*.svg`; цвет задаётся классом без изменения оригинальных SVG.
- В архиве присутствует исходный `assets/world/taos-map.webp`, который **на самом деле содержит XML/SVG**, а не WebP. Он сохранён без изменений, а корректная копия находится по пути `assets/world/taos-map.svg`. Страница мира использует SVG-копию.
- Подсветка контуров карты применяется через CSS, не сохраняется в изображении.
- Точки привязаны к размеру отображаемой карты. Их координаты в `world.html` могут потребовать ручной подгонки под новую географию.
- Фиксированная высота карты и карточки региона на десктопе устраняет скачки при выборе региона. Параллакс карты отключён.
