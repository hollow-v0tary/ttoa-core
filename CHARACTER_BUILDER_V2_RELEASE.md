# THAOS — Character Builder V2

**Дата сборки:** 26 ноября 2026 года  
**Основа:** THAOS Balance V1 / THAOS Lite No Transition  
**Математика:** Core Math 1.2 (тестовая балансировочная редакция)

## Что реализовано

Конструктор находится в `player.html` → «Персонажи» → «Создать персонажа» или «Пересобрать».

В редакторе **ровно семь шагов**:

1. **Облик:** имя, история, загрузка WebP/JPG/PNG портрета с уменьшением для Firebase Spark.
2. **Уровень:** 1–10, выбор на двух небесных кругах Земля (1–5) и Луна (6–10), клик, ползунок и колесо мыши.
3. **Раса:** иллюстрированная карусель/сетка 12 рас с описаниями и расовой Скоростью.
4. **Класс:** визуальная сетка 13 классов с пояснениями и стартовой маной.
5. **Навыки:** двухступенчатый выбор — синий просмотр и золотое закрепление; три базовых навыка на 1–3 уровнях; открытый Путь и его навыки на 4–6. Базовые «Призыв Слуги» и «Развёртывание Устройства» выданы автоматически и не занимают выбор.
6. **Атрибуты:** восемь стартовых очков, повышения на уровнях 5/7/9, два стартовых набора на каждый класс, снятие/надевание вещей внутри выбранного набора, проверка рук/слотов, автоматический расчёт HP, маны, Защиты, Скорости, инициативы, оружейного урона.
7. **Подтверждение:** итоговый лист, проверка ошибок и кнопка «Сохранить персонажа?».

Дополнительно:
- Сохранение созданных/отредактированных персонажей в прежний пользовательский путь `users/{uid}/characters/{characterId}` под `schemaVersion:2`.
- Старые персонажи V1 не переписываются автоматически. При работе с ними действуют предупреждения о смене комплекта.
- Правила Firestore V2 позволяют сосуществовать старым листам V1 и новым V2; права управления сайтом и Мастером не добавляются.
- Сохранение навыков, повышения атрибутов, стартового комплекта, экипировки и истории выбора.
- Пепельник и Пожиратель душ **не выдаются за завершённый контент** и не появляются в доступных пользовательских выборах.
- Для уровня 7–10 Истинный класс и его способности отмечены как **незавершённый контент Мастера**; можно сохранить лист с `breakthroughCompleted:false`, но он не считается полностью готовой высокоуровневой сборкой.
- Нет анимации пепла/снега или переходов по всему сайту. Только локальные мягкие переходы раса → класс.

## Просмотр без Firebase

Откройте **`builder-demo.html`** в папке распакованного проекта. Эта страница использует локальный классический JS и не нуждается в Firebase. Кнопка сохранения выгружает JSON-файл и **ничего не отправляет в облако**.

Это деморежим; данные в нём не сохраняются между обновлениями страницы. Для реального аккаунта используется `player.html`.

## Как установить в существующий GitHub Pages

1. **Сохраните копию** существующего репозитория THAOS и правил Firestore.
2. Распакуйте ZIP и скопируйте содержимое в **корневую папку существующего** локального репозитория (там, где `index.html`). Это замена файлов сайта, а не новый GitHub-проект.
3. Откройте GitHub Desktop, проверьте список изменений, создайте коммит и отправьте его через **Push origin**.
4. В Firebase Console откройте **Firestore Database → Rules**. Сравните актуальные правила с новым файлом `firestore.rules`; убедитесь, что другие изменения в вашей консоли сохранены. Затем опубликуйте объединённые правила. **Загрузка файла `firestore.rules` на GitHub Pages не публикует правила Firebase.**
5. После публикации зайдите в THAOS под реальным игроком, откройте `player.html` и создайте персонажа. Проверяйте разрешения и сохранение в Firestore.

**Не утверждается, что облачное сохранение протестировано на реальном Firebase-проекте.** Протестированы структура выдаваемых V2 документов, соответствие подготовленным полям Firestore V2, локальный интерфейс и вычисления. Реальная запись зависит от опубликованных правил в Firebase Console.

## Источник чисел

HP = `18 + 3*(L-1)`, Защита = `22 + floor((L-1)/3) + бонусы по типам`, базовая Скорость = 5 м с расой и вещами, мана по таблице класса, урон оружия = базовый + `2*floor((L-1)/3)`.

В текущем конструкторе **автоматически** применяются непосредственные бонусы экипировки и пассивный HP-бонус Воина «Здоровое тело». Остальные условные эффекты и навыки Путей не подмешиваются к постоянным характеристикам без численного описания.

Все новые численные параметры остаются **тестовыми** до игрового плейтеста.

## Границы текущей версии

- Нет полного цифрового каталога Истинных классов и чисел для всех навыков Путей; вместо фиктивных эффектов показаны предупреждения.
- Нет свободного получения всех 44 предметов при создании персонажа: доступны два сбалансированных стартовых комплекта каждого класса, и вещи внутри набора можно надевать/снимать.
- Нет автоматического подтверждения Мастером скрытого Пути; существующий скрытый Путь может сохраниться в прежней записи, но игрок не может самостоятельно открыть новый.
- Проверка численных характеристик и комплектов выполняется на клиенте; Firestore Rules проверяют схему и права владельца, **не выступают защищённым серверным античитом**.
- Не меняются фрагменты общего сайта (CMS, бестиарий, разделы мира) и не переписываются опубликованные магические навыки.

## Тесты

- `node tests/check_builder_v2.js` — **5 040 проверок / 0 ошибок** для 13 классов × 12 рас × уровней 1/4/7/10 × 2 комплекта, плюс проверки ограничений.
- `python tests/browser_smoke_v2.py` — пройден путь создания персонажа 4-го уровня, JSON экспорт, повторное открытие, персонаж-призыватель 10-го уровня, проверки интерфейса при ширине 390 px и отсутствия ошибок браузера.
- JS синтаксис: `node --check js/player-app.js` и `node --check js/thaos-builder-engine.js`.
