# THAOS: данные и источники правды

- `../js/class-data.js` — текущий рабочий каталог классов.
- `../js/path-descriptions.js` — текущие описания путей.
- `../js/race-data.js` — текущий рабочий каталог рас.
- `../js/world-data.js` — текущий рабочий источник карты, государств и праздников.
- `world-lore.json` — **копия** государственного лора из `world-data.js`; браузер её сейчас не загружает. Сохраняется для проверки/будущей миграции.
- `classes.json` — не содержит классов, это историческая заглушка. Не используйте как источник данных.

Для первой публичной версии не переписывайте формат персонажей: сохранённые записи Firestore привязаны к действующим `classId`, `raceId`, `pathIndex` и спискам навыков. Полноценная редакторская модель должна поддерживать миграцию данных и стабильные ID.
