# THAOS Lite / Stable — выпуск для первого тестового развёртывания

## Реально сделано
1. Единый `js/common.js` обслуживает публичные страницы: фоновые эффекты, шапку и сообщения; анимация переходов удалена.
2. По просьбе автора убраны и текстовая заставка, и «Пепельная вуаль»: страницы открываются без специального эффекта.
3. Обычные ссылки обрабатываются браузером, без JS-перехвата и дополнительной задержки.
4. Фоновая анимация приостанавливается в скрытой вкладке и отключена при предпочтении уменьшенной анимации.
5. Убрана неиспользуемая старая реализация раскрытия Core `js/core-modules.js`: карточки Core теперь всегда ведут на свои страницы.
6. Модули CMS упорядочены как на главной странице Core; название привилегированной роли в UI теперь «Редактор». Сохранён прежний Firestore `siteAdmins` для совместимости.
7. Исправлена потенциальная гонка появления ссылки Редактора после выхода из профиля.
8. При регистрации/входе запрашивается локальное сохранение Firebase-сессии (при ограничениях браузера — стандартное поведение Firebase).
9. Создана карта текущих источников игрового контента `data/README.md` — чтобы не спутать служебные заглушки и игровые данные.

## Осознанно не менялось
- Игровая механика и баланс; структуры персонажей, групп и индексы путей; Firebase Security Rules.
- Новая роль GM, конструктор DIV и полноценный редактор дерева навыков ещё не реализованы.
- Редактор пока умеет изменять существующие записи; истории версий и создание новых сущностей нет.
- Данные городов, праздников и лора **не были дописаны вымышленными подробностями**. Полноту см. `LORE_AUDIT.md`.

## Ограничения теста
Статический HTTP smoke-test возможен локально. **Полный живой вход и запись в Firebase проверяются только после публикации правил, настройки сервисов и входа под настоящим аккаунтом**.
