THAOS — арты регионов

Здесь размещаются будущие изображения локаций по ID региона из js/world-data.js.

Примеры:
  omand.webp
  ermest.webp
  viriif.webp
  lajdskanet.webp
  grenteynr.webp
  forgotten.webp (Забытое королевство)

ВАЖНО: имя файла должно совпадать с реальным ID региона из js/world-data.js.
Приоритет: regions/<id>.webp, затем .jpg, затем .png.
Если изображения здесь нет, сайт пробует прежнюю assets/world/kingdoms/<id>.*.
Рекомендуемый формат: WebP, горизонтальное 16:10 или 16:9, около 1600–2400 px.
Арт отображается в region.html?id=<id>, в hero-блоке через object-fit: cover.
