# THAOS Lite — изображения без переходной анимации

## Изменения
- Удалена «Пепельная вуаль», затемнение, задержка переходов и экранное появление при смене классов/рас.
- Обычные ссылки работают как стандартные переходы браузера; кнопки предыдущего/следующего класса или расы открывают другую страницу немедленно.
- Арты восьми модулей Core и иллюстрации в их обложках сохранены.
- URL версий CSS/JS изменены для обновления браузерного кэша.

## Загрузка в существующий репозиторий GitHub Desktop
1. Распакуйте архив локально.
2. Откройте существующий репозиторий в GitHub Desktop; при необходимости клонируйте его.
3. Fetch origin / Pull origin, чтобы получить последнюю версию.
4. На всякий случай создайте резервную ветку или сохраните копию текущей папки.
5. В проводнике откройте папку репозитория (Repository → Show in Explorer).
6. Скопируйте **содержимое** распакованного архива в корень репозитория, подтвердив замену совпадающих файлов.
   Не копируйте внешнюю папку целиком; `index.html`, `css/`, `js/`, `assets/` должны находиться в корне, если Pages настроен на `main/(root)`.
   Не удаляйте `.git` и личные файлы, которых нет в архиве.
7. Просмотрите Changes; сделайте Commit to main и Push origin.
8. GitHub → Settings → Pages: `Deploy from a branch`, ветка `main`, каталог `/(root)`.
9. Проверьте `core.html`, `class.html`, `race.html`. При старом кэше нажмите Ctrl+F5.

Firebase для статических иллюстраций не требуется. Не публикуйте секреты, закрытые ключи или пароли в GitHub.
